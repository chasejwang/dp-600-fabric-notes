## 📝 Recap

In this module, you explored how **Dataflows Gen2** use **Power Query** to:

- **Connect to data sources**
- **Apply transformations**
- **Load results to supported destinations**

You saw how the **Power Query Online editor** records each transformation as an **applied step**, creating an **auditable and repeatable process** for data preparation. You also learned how to **optimize dataflow performance** using:

- **Query folding**
- **Preview-only steps**
- The **Modern Query Evaluator**

**Copilot for Dataflow Gen2** can also generate and explain transformation logic with **natural language**.

> [!quote] The payoff
> "For teams with Power Query experience, Dataflows Gen2 bring those familiar skills into **enterprise-scale cloud data preparation without requiring Spark or T-SQL code**. The clean, well-structured data you produce supports **downstream analysts and AI experiences** like Copilot and data agents across the platform." — Microsoft Learn

## 🔑 What you should now be able to do

1. **Describe** what Dataflows Gen2 are and how they differ from Gen1 and Power Platform dataflows.
2. **Pick an output destination** (Lakehouse, Warehouse, ADLS Gen2, Azure SQL, etc.) and an **update method** (Replace, Append, Incremental refresh).
3. **Build a dataflow** in Power Query Online — navigate the editor, apply transformations, clean and standardize data.
4. **Drop down to M** when needed for custom functions, parameterized queries, or advanced logic.
5. **Use Copilot for Dataflow Gen2** to generate and explain transformations.
6. **Optimize** with the Modern Query Evaluator, query folding, preview-only steps, and the standard best practices.
