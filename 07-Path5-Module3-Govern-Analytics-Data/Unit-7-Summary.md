# Unit 7 — Summary

## ✅ What you learned

- Microsoft Purview sensitivity labels classify and protect Fabric items.
- Default labeling, mandatory labeling, and inheritance reduce unlabeled content.
- Promoted, Certified, and Master data represent different trust scopes.
- Descriptions, lineage, impact analysis, domains, and tags improve discoverability.
- OneLake catalog centralizes discovery, governance recommendations, and security management.
- AI agents respect label-based access boundaries, use endorsement as a trust signal, and rely on descriptions for context.
- Prep data for AI improves model quality; Approved for Copilot is the readiness gate.

> [!success] Scenario resolved
> Clear classification, trust signals, and documentation enable both humans and AI agents to select appropriate assets without exposing restricted information or relying on experimental data.

## 🧠 Final exam matrix

| Question | Governance mechanism |
|---|---|
| How sensitive is the data? | Sensitivity label |
| Who may access protected content? | Purview protection policy and Fabric security |
| Can the whole lineage inherit protection? | Downstream inheritance |
| Is this trusted for a team? | Promoted |
| Is this approved organization-wide? | Certified |
| Is this the authoritative reference source? | Master data |
| Where are governance gaps recommended? | OneLake catalog **Govern** tab |
| Is the semantic model ready for AI? | Prep data for AI, then Approved for Copilot |

> [!important] Remember
> Governance is not separate from AI strategy: classification defines boundaries, endorsement guides source selection, and documentation improves grounding.
