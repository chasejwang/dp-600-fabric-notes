# Exercise - Generate an ontology from a Power BI semantic model

> [!warning] Lab summary only
> The public page provides a launch link rather than detailed steps. This note captures the learning purpose, not the lab procedure.

## Prerequisites

- Microsoft Fabric trial or suitable capacity.
- Tenant setting **Enable Ontology item (preview)**.
- Tenant setting **User can create Graph (preview)**.
- A suitable Direct Lake Power BI semantic model.

## What the lab does

The exercise practices generating a complete Fabric IQ ontology from an existing Power BI semantic model, then reviewing and completing the generated structure.

## Skills practiced

- Launch **Generate ontology** from a Direct Lake semantic model.
- Inspect generated entity types, properties, keys, and static bindings.
- Review generated relationship definitions and complete missing bindings.
- Refine technical model names into business vocabulary.
- Validate the populated ontology in Entity type overview.

> [!important] Compare with the manual lab
> The destination is the same. The difference is the starting point: generation reuses trusted model metadata, while manual creation makes every modeling choice explicit.
