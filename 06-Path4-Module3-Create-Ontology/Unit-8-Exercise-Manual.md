# Exercise - Build an ontology manually

> [!warning] Lab summary only
> The public unit launches a separate exercise and does not publish the step-by-step procedure on the unit page. This note summarizes the intended work without recreating the lab.

## Prerequisites

- Microsoft Fabric trial or suitable capacity.
- Tenant setting **Enable Ontology item (preview)**.
- Tenant setting **User can create Graph (preview)**.

## What the lab does

The lab provides hands-on practice building a complete ontology manually in Fabric IQ. Based on the module concepts, the work brings business entity definitions, keys, data bindings, and relationships together into a queryable graph.

## Skills practiced

- Translate source data into business-friendly entity types and properties.
- Choose valid string/integer entity keys.
- Bind static lakehouse data to entity properties.
- Configure relationship types and map both endpoint keys.
- Preview instances and connections to validate the result.

> [!tip] Review first
> Revisit [[Unit-3-Build-Ontology-Manually]], [[Unit-5-Connect-to-Data]], and [[Unit-6-Configure-Relationships]] before launching the exercise.

> [!success] Expected outcome
> A complete manually designed ontology backed by Fabric data and ready for preview and exploration.
